# E-Commerce-Analysis-Power-BI-Dashboard

## Project Overview
This project focuses on analyzing E-Commerce sales data and developing an interactive dashboard using Microsoft Power BI. The dashboard provides valuable insights into sales performance, revenue generation, profitability, customer purchasing behavior, product performance, and business trends to support data-driven decision-making.

## Key Features
- **Sales Performance Analysis:** Monitor total sales, revenue, and order performance.
- **Profit Analysis:** Evaluate profitability and identify high-performing products.
- **Product Analysis:** Analyze product categories and identify top-selling products.
- **Customer Analysis:** Understand customer purchasing patterns and behavior.
- **Time-Based Analysis:** Track monthly and yearly sales trends.
- **Interactive Dashboard:** Explore data using slicers, filters, and interactive visuals.
- **KPI Cards:** Display important business metrics for quick performance monitoring.

## Tools & Technologies
- Microsoft Power BI
- Power Query
- DAX (Data Analysis Expressions)
- Data Modeling
- Data Cleaning & Transformation
- Data Visualization

## Project Objective
To transform raw E-Commerce data into meaningful business insights through interactive visualizations and analytical reporting, helping businesses understand performance, identify trends, and make informed decisions.

## Key Learnings
- Data cleaning and transformation using Power Query.
- Creating DAX measures and calculated columns.
- Building interactive dashboards.
- Analyzing customer, product, and sales performance.
